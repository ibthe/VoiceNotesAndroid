# ВАЖНО: как не получить старую tiny-сборку повторно

Причина предыдущей ошибки — установленный APK реально содержал tiny, несмотря на то, что ожидался base. Значит, одной замены Kotlin-файла недостаточно: надо убедиться, что GitHub Actions использует новый workflow и скачан именно новый артефакт.

1. В репозитории откройте `.github/workflows/android.yml` и замените ЕГО ЦЕЛИКОМ содержимым одноимённого файла из этого архива. Не создавайте вторую копию workflow рядом.
2. Сохраните commit в `main`/`master`. Откройте Actions и выберите workflow `VoiceNotes Android — BASE v0.2.2 VERIFIED`.
3. Запустите `Run workflow`, откройте именно новый зелёный запуск. Последние шаги должны показывать `APK base decoder bytes` больше 100000000 и успешную проверку `whisper-base-int8-v0.2.2`.
4. Скачайте только `VoiceNotes-APK-BASE-VERIFIED-v0.2.2`. Не используйте артефакты из старых запусков.
5. Перед установкой проверьте версию 0.2.2 (versionCode 5) в информации о приложении/свойствах APK. Если Android не позволяет установить поверх старой версии из-за подписи, НЕ удаляйте старую версию до резервного копирования заметок.

Если новый workflow не отображается, проверьте, что изменён файл именно в ветке `main` или `master`, путь начинается с `.github/workflows/`, и commit попал в нужный репозиторий. Если workflow красный, не устанавливайте старый APK — пришлите логи нового запуска.

Сборка APK не выполнялась в среде подготовки; реальную проверку выполняет этот workflow на GitHub.
