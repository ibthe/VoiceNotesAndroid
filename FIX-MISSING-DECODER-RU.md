# Исправление ошибки «в APK не найден tiny-decoder.onnx»

Причина: разные версии workflow могли включать в APK разные варианты декодера Whisper (`tiny-decoder.onnx` или `tiny-decoder.int8.onnx`), а исходный Kotlin ожидал только одно конкретное имя.

В этой версии приложение принимает оба названия и использует тот файл, который действительно находится в `assets/models`. Workflow всегда скачивает мультиязычную Whisper tiny и встраивает INT8 encoder + INT8 decoder + tokens в APK.

Дополнительно после `assembleDebug` GitHub Actions проверяет уже собранный APK: если хотя бы одного файла модели нет внутри APK, job завершается ошибкой и не выдаёт артефакт как успешный.

## Как применить

1. Распакуйте архив.
2. Замените файлы в корне своего GitHub-репозитория содержимым папки `VoiceNotesAndroid-main` (вместе с каталогом `.github`).
3. Выполните commit/push или запустите Actions → Build Android APK (offline Whisper) вручную.
4. Скачайте `VoiceNotes-debug-apk-offline-whisper` только из последнего успешного запуска.
5. Установите новый APK. Если Android не разрешает обновление из-за подписи старой сборки, удалите старую версию и установите новую (при удалении локальные заметки будут удалены, если не экспортированы).

Новая версия приложения: `0.1.1` (`versionCode 2`).
