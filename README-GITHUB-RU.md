# VoiceNotesAndroid — офлайн-распознавание речи

## Что изменено

- Распознавание выполняется локальным движком **sherpa-onnx**.
- Используется мультиязычная **Whisper tiny INT8** (не `tiny.en`), рассчитанная на русский и английский.
- Модель автоматически скачивается **во время GitHub Actions сборки** и включается в APK как assets. На установленном телефоне скачивать модель отдельно не нужно.
- Во время диктовки приложение не обращается к сети и не содержит разрешения `INTERNET`.
- Заметки продолжают храниться в локальной Room-базе.
- Для диктовки записывается до 15 секунд аудио на 16 kHz; после этого выполняется распознавание.

## Сборка через GitHub Actions

1. Распакуйте ZIP и загрузите содержимое папки `VoiceNotesAndroid` в свой GitHub-репозиторий.
2. Убедитесь, что основная ветка называется `main` или `master`.
3. Откройте **Actions** и запустите workflow **Build Android APK (offline Whisper)** (либо сделайте push).
4. Дождитесь окончания workflow. Внизу успешного запуска скачайте артефакт `VoiceNotes-debug-apk-offline-whisper`.
5. Распакуйте артефакт и установите `app-debug.apk` на Android.

Первичная сборка дольше обычной: CI загружает около 100 МБ файлов модели. Сама модель не хранится в исходном ZIP, чтобы архив проекта оставался небольшим; workflow вкладывает её в APK. Поэтому при установке готового APK интернет не нужен для подготовки модели.

## Использование

1. Создайте заметку и нажмите **Диктовать**.
2. Разрешите доступ к микрофону.
3. Говорите до 15 секунд. После автоматической остановки распознавание выполняется локально.
4. Режимы «Авто» и «Смешанная речь» используют автоматическое определение языка Whisper; ручные режимы задают `ru` или `en`.

## Важные ограничения

- Whisper tiny — компактная модель; точность и скорость зависят от устройства, шума и произношения.
- Смешение языков внутри одной фразы поддерживается не идеально и требует проверки на реальных примерах.
- APK будет большим (порядка 100+ МБ из-за модели и нативных библиотек).
- Этот исходный ZIP подготовлен, но сборка не запускалась в данной среде: здесь нет Android SDK/Gradle и сетевого доступа для загрузки зависимостей/весов. Проверить фактический результат можно запуском GitHub Actions.

## Приватность

В приложении не запрашивается разрешение на интернет. Микрофон используется только после нажатия кнопки и выдачи разрешения. Распознавание происходит на устройстве; сохранение заметок выполняется локально.
