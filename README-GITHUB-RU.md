# Сборка VoiceNotes через GitHub

1. На GitHub создайте новый репозиторий, например `VoiceNotesAndroid`.
2. Распакуйте архив и загрузите **содержимое папки `VoiceNotesAndroid`** в корень репозитория (там должны находиться `settings.gradle.kts`, `build.gradle.kts`, `app/` и `.github/`).
3. Откройте вкладку **Actions**. Если GitHub попросит подтвердить использование Actions, подтвердите.
4. После загрузки файлов workflow `Build Android APK` должен запуститься автоматически. Его также можно запустить вручную через **Actions → Build Android APK → Run workflow**.
5. Откройте завершившийся запуск workflow. Внизу страницы, в разделе **Artifacts**, скачайте `VoiceNotes-debug-apk` и распакуйте архив — внутри будет APK.
6. Передайте APK на Android-телефон и установите его. Возможно, Android попросит разрешить установку приложений из данного источника.

## Важно
- Это debug APK для тестирования, не подписанный релиз для Google Play.
- GitHub Actions собирает приложение в облаке. Это не означает, что сами заметки или голос пользователя отправляются в облако во время использования приложения.
- Офлайн-распознавание зависит от языковых моделей и возможностей Android-устройства. Сборка APK сама по себе не гарантирует наличие офлайн-моделей русского и английского языка.
