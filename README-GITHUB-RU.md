# VoiceNotesAndroid — офлайн-распознавание речи

## Что изменено

- Распознавание выполняется локальным движком **sherpa-onnx**.
- Используется мультиязычная **Whisper base INT8** (не `tiny.en`), рассчитанная на русский и английский.
- Модель автоматически скачивается **во время GitHub Actions сборки** и включается в APK как assets. На установленном телефоне скачивать модель отдельно не нужно.
- Во время диктовки приложение не обращается к сети и не содержит разрешения `INTERNET`.
- Заметки продолжают храниться в локальной Room-базе.
- Диктовка записывает аудио на 16 kHz и автоматически завершает запись после паузы либо через 45 секунд. Текст появляется после завершения записи и последующего локального распознавания, не в реальном времени.

## Сборка через GitHub Actions

1. Распакуйте ZIP и загрузите содержимое папки `VoiceNotesAndroid` в свой GitHub-репозиторий.
2. Убедитесь, что основная ветка называется `main` или `master`.
3. Откройте **Actions** и запустите workflow **VoiceNotes Android — Whisper BASE v0.2.1 (strict model check)** (либо сделайте push).
4. Дождитесь окончания workflow. Внизу успешного запуска скачайте артефакт `VoiceNotes-APK-WHISPER-BASE-v0.2.1`.
5. Распакуйте артефакт и установите `app-debug.apk` на Android.

Первичная сборка дольше обычной: CI загружает около 160–180 МБ файлов модели. Сама модель не хранится в исходном ZIP, чтобы архив проекта оставался небольшим; workflow вкладывает её в APK. Поэтому при установке готового APK интернет не нужен для подготовки модели.

## Использование

1. Создайте заметку и нажмите **Диктовать**.
2. При первом запросе разрешите доступ к микрофону; диктовка начнётся автоматически.
3. Скажите фразу и сделайте паузу примерно на 2 секунды. Если пауза не распознана, запись завершится через 45 секунд.
4. Текст появится в поле заметки после окончания локального распознавания. Нажмите **Сохранить**, чтобы записать его в базу.
5. Режим «Авто» и экспериментальный «RU + EN» используют автоматическое определение языка Whisper; ручные режимы задают `ru` или `en`. Для фразы преимущественно на русском с английскими терминами проверьте режим RU.

## Качество распознавания и ограничения

- Выбрана мультиязычная Whisper base INT8 вместо tiny. У неё больше параметров, и она обычно распознаёт точнее, но требует больше памяти и может работать медленнее. Ожидаемый размер встроенных файлов модели — около 160 МБ; итоговый APK будет ещё больше из-за нативных библиотек.
- Режим `transcribe` сохраняет исходный язык речи; приложение не запрашивает режим перевода на английский. Если текст всё равно неправильный, это ошибка распознавания, шум, неверное автоопределение языка или ограничение модели.
- Авто и «RU + EN (экспериментально)» используют автоматическое определение языка. Для преимущественно русской фразы, содержащей английские названия/термины, попробуйте `Русский (RU)`; для преимущественно английской — `English (EN)`. Это языковая подсказка, а не гарантия идеального code-switching.
- Запись длится до 45 секунд и обычно завершается после 2,2 секунды тишины; длинная пауза в середине фразы может остановить запись.
- Для чистого распознавания полезны тихое помещение и разговор рядом с микрофоном.
- Этот исходный ZIP подготовлен, но сборка не запускалась в данной среде: здесь нет Android SDK/Gradle и сетевого доступа для загрузки зависимостей/весов. Проверить фактический результат можно запуском GitHub Actions.

## Приватность

В приложении не запрашивается разрешение на интернет. Микрофон используется только после нажатия кнопки и выдачи разрешения. Распознавание происходит на устройстве; сохранение заметок выполняется локально.
