# Голосовые заметки — Android starter (v0.1)

Стартовый исходный проект Android на Kotlin + Jetpack Compose. Включает локальную базу Room, список/поиск/редактирование заметок, настройки режима речи и строгий вызов встроенного on-device SpeechRecognizer без перехода к облачному распознаванию.

## Открытие
1. Установите Android Studio (актуальная стабильная версия).
2. Откройте папку `VoiceNotesAndroid` как проект.
3. Дождитесь синхронизации Gradle.
4. Запустите на Android-устройстве или эмуляторе с Android 12+.
5. Разрешите доступ к микрофону. Для офлайн-распознавания установите языковые пакеты распознавания речи в системных настройках Google/Android, если они доступны.

## Важно о текущем прототипе
- Заметки сохраняются в локальной Room-базе. `allowBackup=false` отключает резервное копирование Android для приложения.
- Голосовой ввод использует `SpeechRecognizer.createOnDeviceSpeechRecognizer()` и не переключается на сетевой recognizer.
- Доступность офлайн-распознавания и конкретных языков зависит от устройства, прошивки и установленных языковых пакетов.
- Режим «Смешанная речь RU + EN» пока является выбором настройки, но не гарантирует распознавание переключения языков внутри одной фразы. Это нужно реализовать/проверить отдельно на целевых устройствах. Текущая версия отправляет запрос встроенному офлайн-распознавателю и не обещает полноценное code-switching.
- После первого запроса разрешения микрофона нажмите «Диктовать» ещё раз.
- Это исходный starter-проект; перед выпуском необходимы сборка и тестирование в Android Studio, тесты на реальных устройствах, UX-доработки и проверка поведения при ошибках распознавания.

## Стек
- Kotlin, Jetpack Compose, Material 3
- Room Database
- Android on-device SpeechRecognizer
- minSdk 26; для выбранного офлайн API требуется Android 12+ (API 31+)
