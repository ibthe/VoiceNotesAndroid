# О точности распознавания

Используется multilingual Whisper BASE INT8 (не tiny.en и не режим перевода). Модель заметно крупнее tiny и обычно распознаёт точнее, но может быть медленнее на слабых телефонах. Смешанная русско-английская речь не гарантированно распознаётся идеально. Для контроля корректности модели запустите новый workflow `VoiceNotes BASE v0.2.2 — FORCE BASE MODEL AND VERIFY APK SIZE` и устанавливайте только проверенный артефакт `VoiceNotes-BASE-v0.2.2-APK-VERIFIED`.
